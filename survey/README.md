# 🍄 초코송이들 후기 설문 만들기

`Code.gs`를 한 번 실행하면 구글폼 두 개와 응답 시트가 자동으로 만들어져요.

| 만들어지는 것 | 누가 보나요 |
|---|---|
| 🍄 후기 설문 (완전 익명) | 카톡방에 링크 공유 |
| 💌 비밀 쪽지 (선택, 이름 적음) | 후기 제출 뒤 안내 링크로만 들어가요 |
| 후기 응답 시트 | 관리자 (공유해도 괜찮아요) |
| 🔒 비밀 쪽지 응답 시트 | 관리자만 |

두 설문은 서로 연결되지 않아서, 관리자도 누가 어떤 후기를 썼는지 알 수 없어요.

## 1. 설문 만들기 (5분)

1. [script.google.com](https://script.google.com) → **새 프로젝트**
2. 기본 코드를 지우고 `Code.gs` 내용을 통째로 붙여넣기
3. 맨 위 `PARTICIPANTS`에 참가자 이름 입력
   ```js
   const PARTICIPANTS = [
     '홍길동',
     '김철수',
   ];
   ```
   ⚠️ 이름이 들어간 코드는 깃허브에 올리지 마세요. 이 저장소는 공개돼 있어요.
4. 위쪽 함수 선택에서 **createSurvey** → **실행**
5. 권한 승인 창이 나오면
   **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용**
   직접 만든 스크립트라서 나오는 경고예요.
6. 아래 **실행 로그**에 나온 **후기 설문 링크**를 카톡방에 공유하세요.

## 2. 정리본 출력

응답이 모이면 같은 화면에서 함수를 골라 실행하세요. 실행 로그에 구글 문서 링크가 나와요.

- **makeReport** → 후기 정리본
  평균 점수 표, 항목별 분포 막대, 주관식 모음 (순서는 섞여 있어요).
  비밀 쪽지 내용은 없어서 목사님께 보고하거나 공유해도 괜찮아요.
- **makeSecretReport** → 🔒 비밀 쪽지 정리본
  💞 서로 고른 사이, 쪽지 목록. **관리자만 보세요.**

언제든 다시 실행하면 그 시점 기준으로 새 문서가 만들어져요.
출력은 구글 문서에서 **파일 → 인쇄** 또는 **파일 → 다운로드 → PDF**로 하면 돼요.
