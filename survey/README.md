# 🍄 초코송이들 후기 페이지 연결하기

후기 페이지(`review.html`)에서 보낸 응답은 구글 앱 스크립트(`Code.gs`)를 거쳐
관리자 구글 시트에 저장돼요.

| 페이지 화면 | 저장되는 곳 | 누가 보나요 |
|---|---|---|
| 🍄 후기 (익명) | 초코송이들 후기 응답 시트 | 관리자 (공유해도 괜찮아요) |
| 💌 비밀 쪽지 (선택, 이름 있음) | 🔒 비밀 쪽지 응답 시트 | 관리자만 |

후기에는 이름과 제출 시각을 남기지 않고 행 위치도 섞어서 저장해요.
그래서 관리자도 누가 어떤 후기를 썼는지 쪽지와 짝지을 수 없어요.

## 1. 앱 스크립트 준비 (10분)

1. [script.google.com](https://script.google.com) → **새 프로젝트**
2. 기본 코드를 지우고 `Code.gs` 내용을 통째로 붙여넣기 → 💾 저장
3. 맨 위 `PARTICIPANTS`에 참가자 이름 입력
   ```js
   const PARTICIPANTS = [
     '홍길동',
     '김철수',
   ];
   ```
   ⚠️ 이름이 들어간 코드는 깃허브에 올리지 마세요. 이 저장소는 공개돼 있어요.
4. 위쪽 함수 선택에서 **setup** → **실행**
   - 권한 승인 창이 나오면 **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용**
     (직접 만든 스크립트라서 나오는 경고예요)
   - 내 구글 드라이브에 응답 시트 두 개가 만들어져요.

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙️ → **웹 앱**
3. 설정
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)
5. 이 URL을 `review.html`의 `ENDPOINT`에 넣으면 끝이에요. (Claude에게 URL만 보내도 돼요)

> 명단을 고치거나 코드를 바꾼 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야
> 페이지에 반영돼요. URL은 바뀌지 않아요.

## 3. 정리본 출력

응답이 모이면 스크립트 화면에서 함수를 골라 실행하세요. 실행 로그에 구글 문서 링크가 나와요.

- **makeReport** → 후기 정리본
  평균 점수 표, 항목별 분포 막대, 주관식 모음 (순서는 섞여 있어요).
  비밀 쪽지 내용은 없어서 목사님께 보고하거나 공유해도 괜찮아요.
- **makeSecretReport** → 🔒 비밀 쪽지 정리본
  💞 서로 고른 사이, 쪽지 목록. **관리자만 보세요.**

언제든 다시 실행하면 그 시점 기준으로 새 문서가 만들어져요.
출력은 구글 문서에서 **파일 → 인쇄** 또는 **파일 → 다운로드 → PDF**로 하면 돼요.
